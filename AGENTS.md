# Better Spirit Commerce

Forge 1.20.1 / Java 17; mod ID `better_spirit_commerce`;
base package `com.bettercontent.spiritcommerce`.
Owns credited-kill spirit release, eight profession/market identities, resident barter and scheduled themed traders.
Wandering spirit commerce and economy-driven villages are separate systems; read
[their gameplay boundary](docs/commerce-systems.md) before catalogue or economy work.
No identity aliases or migrations.
Source/staging gate: `./gradlew verifyFull stageRuntimeJar`.

Read [shared workspace policy](../../better-content-modpack/docs/policies/workspace.md)
and its linked testing/retention policies. Docs-only changes use the shared document check
and `git diff --check`, not unrelated runtime builds.
